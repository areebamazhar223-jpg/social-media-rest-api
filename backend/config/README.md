# Social Media REST API

A backend project built with Node.js, Express.js, MongoDB, and Mongoose.

## Features

- User signup and login
- JWT authentication
- Create posts
- Like and unlike posts
- Like count and status
- Comments API
- Follow and unfollow users
- User profile APIs
- Notification APIs

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
- Postman

## Run Locally

1. Install Node.js and MongoDB.
2. Open the project folder in the terminal.
3. Run `npm install`.
4. Create your own `.env` file with the required configuration.
5. Start the server using `node backend/server.js`.

## Purpose

This project was created to practise REST API development, authentication, database models, controllers, routes, and API testing using Postman.
